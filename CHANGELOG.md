# История версий

## v0.26 — 2026-11-23
- Новый раздел «Задачи из анализа» (группа «Менять в Jira»): ссылка на страницу системного анализа в Confluence → разбор → предпросмотр → создание задач.
- Разбор страницы по шаблону СА: название продукта и дата запуска из заголовка, ссылки на эпики из блока «Ссылки», источники из таблицы 3.1, пункты раздела 3 (в том числе оформленные обычным текстом), подразделы «Системного анализа», примеры сценариев.
- Декомпозиция: «анализ СТ и источников», «реализация расчёта в DWH», по задаче на каждое дополнительное место доработки (например, бандл) и одна задача «тест-кейсы и тестирование».
- Описания — таблицей по шаблону «доработка продукта» или «разработка продукта» (Confluence ORBARB «Шаблоны описаний для постановки задач»); незаполненные поля помечены «⚠ заполнить», перед созданием есть предупреждение.
- Проверки перед созданием: эпик DWH закрыт, похожие задачи уже есть в проекте, обязательные поля Jira, которые программа не заполняет.
- Название, исполнитель и описание каждой задачи можно поправить в предпросмотре; лишние задачи снимаются галочкой.
- Эпик ставится в поле «Epic Link»; если поле недоступно на экране создания — задача связывается с эпиком ссылкой.
- Отдельное подключение к Confluence (свой адрес и Personal Access Token), токен только в памяти. Результат создания пишется в `jira_toolkit_data/created_*.json`.

## v0.25 — 2026-11-23
- Структура эпика: раскладка по папкам — по проекту (по умолчанию), типу задачи, исполнителю или статусу. Эпик наверху, под ним папка на каждую группу; внутри папки задача стоит под ближайшим предком из той же группы.
- Папки видны в дереве (сворачиваются), попадают в столбец «Папка» в CSV и создаются в структуре Jira (REST Structure `/item/create`).
- Если версия Structure не даёт создавать папки, структура всё равно создаётся — задачи сгруппированы подряд, без папок, с предупреждением и текстом ошибки.
- Пустые папки (где все задачи без доступа или убраны) не создаются.
- Подсказки «?» в строке параметров теперь всплывают поверх и не сдвигают блоки; закрываются кликом мимо или Esc.

## v0.24 — 2026-11-20
- Новый интерфейс: боковое оглавление с группами «Смотреть» и «Менять в Jira», отдельный экран подключения, статус подключения внизу слева.
- «Дашборд» разделён на «Метрики» и «Доски в Jira».
- Предпросмотр массовых изменений в виде «было → станет»: добавляемое синим, убираемое зачёркнуто красным; кнопка записи показывает число изменений.
- Метрики: крупное число, превышение порога выделяется маркером, критичное — красным, подпись с порогом.
- Пояснения убраны в сворачиваемые блоки «?», добавлены пустые состояния, ключи задач моноширинным шрифтом, табличные цифры.
- Логика и API не менялись.

## v0.23 — 2026-11-19
- Новая вкладка «Связанные задачи»: выгрузка всех задач, связанных с указанной (дата создания, тип связи, статус, значения выбранных полей Jira).
- По умолчанию в колонки выводятся поля «Наименование клиента» (КУС клиента) и «ID Клиента» (реф. ID партнёра); список полей настраивается.
- Поиск КУС по ссылке партнёра в описании задачи с пометкой «проверить» для неоднозначных случаев и ручной правкой в таблице.
- Сводка по статусам и по дням, поиск, фильтр «только проверить», исключение задач крестиком, выгрузка в CSV.

## v0.22
- Массовые изменения с журналом и откатом, дашборд по ролям, генерация дашбордов в Jira, структура эпика с выгрузкой в CSV и созданием структуры в плагине Structure.
