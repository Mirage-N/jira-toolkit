# Jira Toolkit v0.24

Локальный помощник над Jira (on-prem, Jira DC 10.x). Работает на вашем компьютере, только стандартная библиотека Python 3.8+, ничего устанавливать не нужно.

## Запуск
- Windows: двойной клик по `run_windows.bat` (или `python jira_toolkit.py`)
- macOS/Linux: `./run_mac_linux.sh`

Откроется страница http://127.0.0.1:8765. Укажите адрес Jira и свой Personal Access Token
(Jira → профиль → Personal Access Tokens → Create token) и нажмите «Подключиться».

## Что умеет
Интерфейс: слева оглавление — «Смотреть» (Связанные задачи, Структура эпика, Метрики) и «Менять в Jira» (Массовые изменения, Доски в Jira, Журнал и откат).

1. **Массовые изменения** — список задач → предпросмотр «было → станет» → запись → журнал и откат.
2. **Дашборд** — карточки-метрики по JQL с порогами, наборы под роли. Раздел «Создать дашборды в Jira»: из проекта(ов) создаёт два дашборда («Рабочий» и «Статистика разбора потока») с фильтрами и стандартным набором гаджетов; сначала предпросмотр, потом создание.
3. **Структура эпика** — дерево задач, подзадач и связей со статусами, датами и временем в работе; крестиком можно убрать лишнее; выгрузка в CSV; кнопка «Создать структуру в Jira» (плагин Structure) и формула «Дней в работе».

4. **Связанные задачи** — укажите задачу (например, INCIDENT-1027), получите все связанные с ней задачи: дата создания, ссылка, тип связи, статус и значения выбранных полей Jira (по умолчанию «Наименование клиента» = КУС клиента и «ID Клиента» = реф. ID партнёра). КУС по ссылке партнёра ищется в описании; сомнительные строки помечаются «проверить», значение можно поправить прямо в таблице. Можно убрать лишние задачи крестиком, отфильтровать, выгрузить в CSV (открывается в Excel).

## Формула «Дней в работе» (Structure)
После построения структуры в программе раскройте блок «Формула», скопируйте текст. В Structure: колонка → тип «Формула» → вставить.
В блоке «Имена» привяжите: `resolved` → «Дата резолюции», `status` → «Статус», `created` → «Создано».

## Безопасность
- Слушает только 127.0.0.1.
- Токен хранится только в памяти процесса, на диск не пишется и никуда, кроме вашей Jira, не уходит.
- На диск (папка `jira_toolkit_data`) пишутся настройки дашборда и журналы изменений — без токена.
- Не присылайте и не публикуйте cURL-запросы из браузера: в них есть cookie сессии.

## Известные ограничения
- Гаджет «Время в статусе» (Alfa-Bank) на дашборд добавляется вручную.
- Если дашборд уже существует, программа предлагает пропустить или создать новый; лишние копии удаляйте вручную.
- Массовые изменения пишут в Jira — сначала пробуйте на 1–2 задачах.

## Обратная связь
Если что-то не сработало — пришлите текст ошибки из программы и (если есть) файл из `jira_toolkit_data` (`dashgen_*.json`, `journal_*.json`).

## Разработка
- Вся программа — один файл `jira_toolkit.py` (Python 3.8+, только стандартная библиотека). Интерфейс — HTML/JS в константе `PAGE` в том же файле.
- Новая функция = отдельная вкладка: обработчик `/api/<раздел>/...` в `Handler.do_POST`, фоновая задача через `new_job()`, разметка `<section id="t-...">` и JS-блок в `PAGE`.
- Перед коммитом поднимайте номер версии (заголовок страницы, шапка, README) и добавляйте запись в `CHANGELOG.md`.
- Не коммитьте папку `jira_toolkit_data`, выгрузки CSV, токены и cURL-запросы из браузера.
